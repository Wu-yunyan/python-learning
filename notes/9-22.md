# Linux 命令总表

---

## 一、文件与目录

| 命令 | 作用 | 实际工作用在哪 |
|---|---|---|
| `pwd` | 显示当前所在目录 | 排查任何问题前先确认"我在哪" |
| `ls` | 列出目录内容 | —— |
| `ls -l`  | 长格式：权限 ｜ 属主 ｜ 大小 ｜ 时间 | **第 1 列那 10 位就是权限串**，安全核查第一眼 |
| `ls -a` | 含隐藏文件（`.` 开头） | 找 `.bash_history`、`.ssh/`、`.gitignore` |
| `ls -la` | 上面两个合并（最常用） | —— |
| `ls -ld 目录` | 看**目录本身**的权限，不是里面的内容 | 上传目录是不是 777，看的就是这条 |
| `ls -lt` / `ls -ltr` | 按修改时间排（`r` 反过来） | **找最近被改过的文件** = 找 webshell 的常用手法 |
| `cd` `cd ..` `cd ~` `cd -` | 切换 / 上一级 / 回家 / 回跳上次 | —— |
| `mkdir` `mkdir -p` | 建目录 / 一次建多层 | —— |
| `touch` | 建空文件 / 改时间戳 | —— |
| `cp` `cp -r` | 复制文件 / 目录 | 动生产配置前先 `cp` 备份，改错能回滚 |
| `mv` | 移动 / **改名** | —— |
| `rm` `rm -r` `rm -f` | 删除 / 删目录 / 强制不提示 | 删前必先备份；`rm -rf` 是服务器的头号杀手 |
| `rmdir` | 删**空**目录 | 比 `rm -r` 安全：目录非空它会拒绝 |

**两条必记**：`cp a b` = 变成两份；`mv a b` = 还是一份（只是改了名）。
`ls -l` 行首：`d` = 目录，`-` = 普通文件。

## 三、文本处理与管道

| 命令 | 作用 | 实际工作用在哪 |
|---|---|---|
| `grep 关键词 文件` | 在文件里找含关键词的行 | 日志检索的第一步 |
| `grep -i` | 忽略大小写 | 日志里 `Failed` / `failed` 混着写，必须加 |
| `grep -v` | 反选（不包含的） | 排除噪音行（如过滤掉注释、空行） |
| `grep -n` | 显示行号 | 定位到第几行，方便回头查 |
| `grep -c` | **只输出匹配的条数** | 数爆破次数就用它（比管道接 `wc -l` 更稳） |
| `grep -r 关键词 目录` | 递归搜整个目录 | 在网站目录里搜一句话，找 webshell |
| `grep -E` | 扩展正则：一次匹配多个关键词（词之间写竖线 = "或"） | 一条命令同时查 ssh / http / https / mysql 四个端口 |
| **管道** | 把左边命令的输出，喂给右边当输入 | 所有"组合拳"的粘合剂，例见下方 |
| `>` | 覆盖写（原内容没了） | 生成报告文件 |
| `>>` | 追加写（接在末尾） | **写日志一律用 `>>`**，用 `>` 日志会被清空 |
| `2>/dev/null`  | 把**错误输出**丢掉 | `find` 遍历无权访问的目录会刷屏，靠它清屏 |
| `wc -l` | 数行数 | 数"输出有几行"（数文本里匹配几条用 `grep -c`） |
| `sort` | 按行排序 | 配合 `uniq` 统计"谁出现最多" |
| `uniq -c` | 去重并数每项出现几次 | **合并 `sort` 用**，找出现次数最多的 IP |
| `awk '{print $N}'` | 按列取值 | 从日志里抠出 IP 那一列 |

```bash
# 管道：先筛出失败登录的行，再数有几条
grep "Failed password" /var/log/auth.log | wc -l

# grep -E：一次查出四个常见端口登记
grep -E "^(ssh|http|https|mysql)" /etc/services
```

## 四、权限与用户

| 命令 | 作用 | 实际工作用在哪 |
|---|---|---|
| `ls -l` 第 1 列 | 10 位权限串：类型 + 属主 + 属组 + 其他人 | 一眼看出"谁能读、谁能写、谁能执行" |
| `chmod 755 文件` | 数字法：**赋值**，没写到的位全变 0 | 目录 / 公共脚本 |
| `chmod 644 文件` | 属主可写、其他人只读 | 普通文件、网页文件 |
| `chmod 600 文件` | 只有属主能读写 | **私钥、含密码的配置**，必须 600 |
| `chmod u+x` `go-w` `a-x` | 字母法：**只动指定那几位** | 给脚本加执行权用 `u+x` 最安全，不会误改别人 |
| `chown 用户:组 文件` | 改属主和属组 | 网站目录必须归 Web 服务账号，否则服务读不了 |
| `umask` | 决定新建文件的**默认权限** | `0022` → 文件 644、目录 755；调它 = 改全局默认 |
| `sudo` | 以 root 身份执行**一条**命令 | 生产标准做法，且每次执行都记进 `/var/log/auth.log` |
| `su` | 切换用户（要 root 的密码） | 切过去就一直待着，生产上基本不用 |
| `sudo -l` | 看"我被允许执行哪些命令" | **权限审查第一招**；若给某账号 `NOPASSWD: ALL` = 提权后门 |
| `whoami` / `groups` | 我是谁 / 我在哪些组 | 确认权限边界 |
| `find / -perm -4000`  | 找带 **SUID** 位的文件 | **提权排查第一招**：攻击者靠配错的 SUID 程序跳到 root |

**数字法 vs 字母法的根本区别**&#8203;：数字法是赋值，字母法是增量。
**权限三位含义**：r=4 读、w=2 写、x=1 执行；三个身份各一组 → `755` = 属主 rwx、其他 r-x。

## 五、查找文件：find

**固定三段结构**：`find [去哪儿找] [按什么筛] [找到后干什么]`

| 写法 | 作用 | 用在哪 |
|---|---|---|
| `find ~ -name "*.sh"` | 按名字找 | 最基础的一层 |
| `find ~ -type f` | 只要文件（`d` = 只要目录） | 排除目录干扰 |
| `find ~ -type f -name "*.sh" -mtime -3` | **最近 3 天内改动过的** | **找 webshell 的标准姿势**：被改过的脚本最可疑 |
| `sudo find / -perm -4000 -type f 2>/dev/null`  | 全系统找 SUID 文件 | 提权点排查：记住系统默认那几十个，**多出来的陌生文件就可疑** |
| `find / -size +500M` 〔讲〕 | 找大于 500M 的文件 | **磁盘满了**：先 `df -h` 看哪个分区满，再按大小找人 |

## 六、系统与安全日志

| 命令 / 文件 | 作用 | 用在哪 |
|---|---|---|
| `/etc/passwd` | 系统账号台账 | 看 `UID=0` 的账号（除 root 外都是提权后门）；`grep -c nologin` 数服务账号 |
| `/etc/shadow` | 存放密码哈希（仅 root 可读） | 密码策略核查 |
| `/var/log/auth.log` | 认证日志（登录 / sudo / su） | **判断 SSH 爆破的主战场** |
| `grep -c "Failed password" /var/log/auth.log` | 数失败登录次数 | 几十 = 有人输错；**几百上千 = 有人在爆破** |
| `grep -c "Accepted password" ...` | 数**成功**登录次数 | 失败之后出现成功 = **已经撞对了 → 立刻处置**（改密码、封 IP） |
| 找"失败次数最多的来源 IP" | 从失败日志里数出哪个 IP 试得最多 | 锁定攻击源用于封禁；组合命令见下方 |
| `history` | 看历史命令 | 应急响应必查：**`history -c` 清空过本身就是可疑信号**（攻击者抹痕迹） |
| `df -h` 〔讲〕 | 看各分区磁盘占用 | 磁盘告警第一步 |
| `sudo grep -c nologin /etc/passwd` | 数"禁止登录"的服务账号 | 基线核查：该禁的都禁了吗 |
| `Ctrl+C` / `Ctrl+Z` | 终止进程 / **挂起**（挂起 ≠ 终止） | 卡住的命令：`jobs` 看编号 → `kill %N` 清掉；`fg` 拉回前台 |

```bash
# 找出爆破源 IP：筛出失败行 → 抠出 IP 那列 → 数每个 IP 出现几次 → 倒序取第一
grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn | head
```
逐段读：`grep` 筛 → `awk` 取 IP 列 → `sort` 排序 → `uniq -c` 计数 → `sort -rn` 按次数倒排 → `head` 只看第一名。

## 七、网络与端口

| 命令 | 作用 | 实际工作用在哪 |
|---|---|---|
| `ss -tunlp`  | 看本机**正在监听的端口**和对应进程 | 基线核查"不该开的口开没开"；**发现陌生端口 = 可能被种了后门 / 挖矿** |
| `netstat -tunlp` | 同上（老命令） | CentOS 7 后逐渐被 `ss` 取代（`ss` 更快），但面试官爱问，两个都要认 |
| `/etc/services` | 「端口 ↔ 服务名」登记表 | 看到陌生端口号来这儿对名字；**它只是登记表，不代表真装了那个服务** |
| `nc -zv 主机 端口` | 探测端口通不通 | 分清"连不上"是哪一种：**refused = 服务没起；超时 = 网络 / 防火墙拦了** |
| `openssl s_client -connect 域名:443 -servername 域名` | 亲手做一次 TLS 握手，看证书链 | 等保 / 安全评估必查：证书过期没、签发者是谁（`subject` / `issuer` / `Validity`） |
| `curl -I http://...`  | 只看响应头 | 看是 **301 永久跳转（真强制 HTTPS）**&#8203; 还是 302（可能被绕过）；`Server: nginx/1.14.0` = 版本泄露 |
| `lsof -i:8080` 〔讲〕 | 按端口反查进程 | 已知端口号找"哪个程序占着" |
| `ip addr` 〔讲〕 | 看网卡和 IP | 排查"网络不通"第一步 |
| `sudo iptables -L -n` 〔讲〕 | 看防火墙规则 | 排查是不是被防火墙拦了 |

** 端口常识**：22 SSH（加密）｜80 HTTP（明文）｜443 HTTPS（TLS 加密）｜3306 MySQL｜3389 RDP 远程桌面（**爆破重灾区**）｜445 SMB（**永恒之蓝 / WannaCry 的入口**）｜8080 常见 Web 备用。

## 八、脚本与定时任务（9/18）

| 命令 / 写法 | 作用 | 用在哪 |
|---|---|---|
| `echo "内容"` | 打印到屏幕 | 脚本里打日志（`echo "$(date) 备份开始" >> x.log`）；`echo $PATH` 查命令到哪找 |
| `#!/bin/bash`  | **shebang**：告诉系统用哪个解释器 | 不写 → 被 `sh` 跑 → **手动能跑、crontab 就报语法错** |
| `chmod +x 脚本` | 给脚本加执行权 | 不加就是 `Permission denied` |
| `./脚本.sh` | 按 shebang 指定的解释器执行 | 对比 `sh 脚本.sh`（强行用 sh 跑，shebang 被当注释忽略） |
| `crontab -e` / `-l` | 编辑 / 查看定时任务清单 | 定时备份、定时巡检；格式 `分 时 日 月 周 命令` |
| `jobs` / `kill %N` / `fg` | 看后台挂起的任务 / 按编号清掉 / 拉回前台 | 处理误按 `Ctrl+Z` 卡住的命令 |

**运维最经典的幽灵故障**：脚本手动跑正常、加到 crontab 就不执行。三查：
① 有没有写 shebang ② 命令是不是绝对路径（cron 的 PATH 很短）③ 是不是用了相对路径（cron 的工作目录不是脚本所在目录）。

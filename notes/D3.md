# D3 复盘 2026-09-10

## 学了什么
- 循环：`for` + `range`（重点：左闭右开，1 到 100 要写 `range(1, 101)`）
- 循环控制：`break` / `continue`
- 嵌套循环：九九乘法表（`end='\t'` 让结果横排）、直角三角形、金字塔
- 字符串进阶：`upper/lower/strip/replace`（不改原串，要接住返回值）、
  `split`（切成列表）/ `join`（拼回）、`find`（找不到返回 -1）、`startswith/endswith`
- 切片：`word[开始:结束:步长]`，含开始不含结束；`word[::-1]` 一步反转

## 卡过的地方
- 嵌套循环转不过来 → 一句话：**外层走一步，内层跑一整圈**；看内层时把外层当固定的数
- 金字塔公式 → 缩小规模，找规律
- `print()` 自带换行，想要横排得写 `end='\t'` 或 `end=''`

## 自己的理解
- 双重循环像时钟：秒针跑满一圈分针才动一格，**最内层跑得最勤**
- 字符串方法都返回新串，原串不变 → 必须 `s = s.strip()` 才生效

# D2 复盘

## 学了什么
- `if` / `elif` / `else`（缩进 4 空格是语法，不是排版）
- `match` / `case`：守卫模式 `case x if 条件:`
- 字符串基础：单双引号等价、f-string、`len()`
- `try` / `except`：拦截运行时崩溃

## 卡过的地方
- `match` 的值模式只能精确匹配，89.5 会掉进兜底 → 改 `case x if x >= 80`
- `=` 是赋值，`==` 是判断
- `float('abc')` 直接抛 ValueError → 用 try/except 接住

## 自己的理解
- `input()` 拿到的永远是字符串，算数必须 `int()` / `float()`
- `if` 管业务分支，`try/except` 管别让程序崩，两套工具

## 产出
- `grade.py`：match + if/elif 两个版本，含边界与无效输入兜底

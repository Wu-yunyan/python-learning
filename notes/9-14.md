# D4–D5 复盘 · 2026-09-14

## 学了
- 字典：`{键: 值}`、取值 `d[键]` vs 安全取值 `d.get(键, 默认值)`、增改、`del`、`for k,v in d.items()`
- 文件：`with open(路径, 'w'/'r'/'a', encoding='utf-8') as f`、`f.write()`、`for line in f`、`line.split(',')`

## 卡 / 坑
- 手机号用 `int()` 存 → 前导 0 丢失（`013800138000` → `13800138000`），带横线直接 ValueError
  → 手机号 / 身份证 / 银行卡一律用 `str`，不做算术
- 查不存在的键用 `d[键]` → KeyError 崩 → 用 `d.get(键, 默认值)`
- `contacts.get('name1','无')` 变量名加了引号 → `'name1'` 变成字符串，永远查不到

## 一个理解
- `save` 是「字典 → 文件」，`load` 是「文件 → 字典」，一对反操作。
- load 里的 `try/except FileNotFoundError` 是为了第一次运行还没有这个文件 —— 不兜住程序就崩。
